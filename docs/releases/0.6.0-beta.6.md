# WHOOP Lens Android 0.6.0-beta.6 candidate

Android versionCode: 13

Everything in 0.6.0-beta.5, plus the refresh error state from `main` (PR #123, merged into this branch):

- When a WHOOP read or a Health Connect read fails during a foreground refresh, Home shows one coral card, "Couldn't load. Your saved data is still shown.", with a 48 dp **Retry** button. Saved values stay visible. Being offline is still reported as offline, and record-limit notices ("latest 1,000 records shown") are not treated as failures.
- A successful refresh now reads "Dashboard refreshed".

Signed, when published, by the WhoopLens release key with v3 key rotation, like beta.5. It installs over beta.5 in place.

This candidate is not a published update. Signing and publication require the protected Android release workflow and owner approval; never replace an existing release or tag, or reuse its versionCode.

Device checks still needed for this candidate: the error banner's appearance in Glass, Reduced transparency and Battery saver; TalkBack reading the banner; Retry after restoring connectivity.
