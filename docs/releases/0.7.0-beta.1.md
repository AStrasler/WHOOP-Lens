# WHOOP Lens Android 0.7.0-beta.1

Prerelease test candidate. It is **not** proof that every hardware acceptance item has passed.
The 0.6.0-beta.5 results on the Galaxy S26 Ultra apply to beta.5 only.

Install over the current app. Do not uninstall or clear data. The package, signing key and
key-rotation lineage are the same as beta.5, so it updates in place.

## What's in this release

- **Liquid Glass and app-wide cleanup (#112).** Measurement attribution, timestamps and
  warnings stay with each value. Extended provenance moves to Sources & Freshness. Charts use
  collision-free timestamps and layouts that respect density and font size. Refresh banners:
  "Dashboard refreshed" and "Couldn't load. Your saved data is still shown.", plus WHOOP and
  Health Connect read-failure notices.
- **Manual cloud sync (#112).** Choose categories, review the exact records, then sync. Pause
  (keeps the cloud copy) and withdraw (deletes it) are available. Fixes: a blank Health
  Connect workout title no longer fails the whole sync; review uses only the current
  account's categories; an account that has never synced shows "Not synced yet". Server-side
  sync stays off until production activation is separately approved.
- **Background Direct BLE (#100).** A connected strap session now keeps running when you
  leave the screen, switch apps, lock the phone, or answer an OS pairing prompt, with an
  ongoing notification and a Stop button. The notification never shows heart rate or other
  readings; the lock screen shows only "Direct BLE session active". The session stops if you
  tap Stop, swipe the notification away, swipe WhoopLens from Recents, turn notifications off
  or block them, sign out, switch accounts, turn Bluetooth off, or after two failed
  reconnects. Reconnect resumes the same strap without a new scan. Still only the standard
  heart-rate service; no WHOOP commands and no uploads.
- **Widgets (#102).** All seven widgets, including the WhoopLens status widget, start at 1×1.
  Maximum resize hints are now 284×180dp. At one cell the status widget shows one word (Sign in
  / Unlock). Values no longer clip at one-row and landscape sizes. Settings → Widgets &
  privacy → Placed widget sizes shows the sizes the launcher reports, for measurement.
- **MCP parity (#121, server side).** `set_life_schedule`, `get_companion_sync_status` and
  `pause_companion_sync` for MCP-only members. These ship with the server, not this APK, and
  remain off in production until separately approved.
- **Test reliability (#126).** Hardened browser test start-up and diagnostics. No app change.

## New Android permissions

| Permission | Why |
| --- | --- |
| `FOREGROUND_SERVICE` | Required to run any foreground service |
| `FOREGROUND_SERVICE_CONNECTED_DEVICE` | Declares the background Direct BLE session as a connected-device service (Android 14+) |
| `POST_NOTIFICATIONS` | Shows the session notification with Stop. Asked once on the Direct BLE screen. If declined, Direct BLE stays foreground-only |

No location, wake lock, boot start or health write permissions. Owner-approved for this beta.

## Known limitations

- **4×2 widget maximum not verified.** Android launchers turn the dp hint into cells with their
  own rounding; on narrow 5-column grids a fifth column may still be allowed. Needs S26 Ultra
  measurement (#130).
- **Background BLE timing.** Without a wake lock, a reconnect or timeout can run late while the
  phone's CPU sleeps. Nothing is collected while waiting. Samsung battery settings might end
  background sessions; to be checked (#129).
- **Website Life Schedule settings** are not built; they need an approved member web sign-in
  (#128).
- **Codex Security Review** (research preview) did not run on this repository. Security was
  checked by Codex code reviews focused on security, Semgrep, dependency audit, Android lint
  and a manual inspection instead.
