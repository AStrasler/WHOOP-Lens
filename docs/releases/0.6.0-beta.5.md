# WHOOP Lens Android 0.6.0-beta.5

Android versionCode: 12

Same app as 0.6.0-beta.4. This is the first release signed by the dedicated WhoopLens release key (`8A:A3:A7:…:7C:80`), with APK Signature Scheme v3 key rotation from the original Android Debug key (`C3:E4:F5:…:F5:78`). See `docs/ANDROID_RELEASES.md` on `main` (PR #125).

Install over the current app. Do not uninstall or clear data: the rotation lets the installed app update in place and keep its sign-in and saved data. App Links (`/.well-known/assetlinks.json`) list both fingerprints.

After this update, APKs signed only by the original key (for example local debug builds) cannot install over the app; uninstall first for those.
