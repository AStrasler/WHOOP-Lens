# 0.7.0-beta.1 — Galaxy S26 Ultra acceptance checklist

Record pass, fail or not tested for each item, with the date. A failure is a result, not a
reason to skip the rest. Don't uninstall or clear data at any point. WHOOP 5.0 checks wait for a
5.0 strap.

Before starting: record the Android and One UI build, the home-screen grid, font size and
display zoom. Confirm Settings → About & help shows **0.7.0-beta.1**.

## 1. In-place upgrade from beta.5
- [ ] Install the APK over beta.5 without uninstalling. Android does not ask to uninstall.
- [ ] Still signed in; dashboard shows saved data before refresh.
- [ ] Health Connect permissions unchanged (Settings → Health Connect).
- [ ] Pull to refresh: "Dashboard refreshed" or the "Couldn't load…" banner with saved data still shown.

## 2. Direct BLE with the MG (Settings → Direct BLE)
- [ ] First scan asks for Nearby Devices and Notifications. Allow both.
- [ ] Connect to the MG; a live heart rate appears; an ongoing notification appears.
- [ ] Leave the screen, switch apps, and lock the phone for 2+ minutes. Unlock: readings continued; notification still there.
- [ ] Lock screen shows only "Direct BLE session active". No heart rate anywhere in the notification.
- [ ] Each ends the session and removes the notification (reconnect between tests):
  - [ ] Stop in the app.
  - [ ] Stop in the notification.
  - [ ] Swipe the notification away.
  - [ ] Swipe WhoopLens away in Recents.
- [ ] After a stop, Reconnect connects to the MG without scanning.
- [ ] Bluetooth off during a session ends it; nothing reconnects by itself after two retries.
- [ ] Turn WhoopLens notifications off in Settings, start a session, leave the app: the session stops.
- [ ] Note whether Samsung battery settings (Sleeping apps) end a long background session.

## 3. Widgets
For each of the seven widgets (remove and re-add any existing ones first):
- [ ] The picker preview footprint matches the placed footprint; places at 1×1.
- [ ] Resize to the largest allowed. Record the span and the matching line from Settings → Widgets & privacy → Placed widget sizes. Note whether it goes past 4 columns or 2 rows.
- [ ] At the largest font size, no clipped text; TalkBack reads the full description.
- [ ] The WhoopLens status widget at 1×1 shows Sign in or Unlock.
- [ ] Lock screen → Add widgets: record whether WhoopLens is offered (not expected).

## 4. Cloud sync and refresh
- [ ] Cloud synchronization card shows a status. "Service activation required" is expected while server sync is off.
- [ ] Choosing categories says no upload was authorized.
- [ ] Review & sync now is disabled or shows "Choose sync categories…" until categories are chosen for this account.

## 5. Sign-out and sign-in (App Links)
- [ ] Sign out: credentials and previews cleared; widgets show signed-out text; any BLE session ends.
- [ ] Sign in: the browser hands back to WhoopLens directly (no "Open with" chooser), and data returns.
