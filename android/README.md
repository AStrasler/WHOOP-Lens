# WHOOP Lens companion (draft scaffold)

This private-beta Android 14+ project uses the stable Health Connect client 1.1.0. No data is read or uploaded; this is deliberately not a beta APK. The next build must add verified Supabase user authentication, individual Health Connect permission grants, preview, deliberate sync and deletion controls, device tests, and a pinned Gradle wrapper. No service-role keys should be bundled in the app. Requires JDK 17+, Android SDK API 35 and Gradle compatible with Android Gradle Plugin 8.9.2. The skeleton is not for distribution.
